# 权限

每次后端请求验证 Access JWT 对应的服务端会话仍有效，再检查工作空间及项目成员关系。非成员访问项目资源返回 404，避免泄露资源存在性。

| 操作 | OWNER | DIRECTOR | EDITOR | REVIEWER | VIEWER |
| --- | --- | --- | --- | --- | --- |
| 项目读取 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 内容与故事编辑 | ✓ | ✓ | ✓ |  |  |
| 发起生成 | ✓ | ✓ | ✓ |  |  |
| 审核批准 | ✓ | ✓ |  | ✓ |  |
| 时间线编辑 | ✓ | ✓ | ✓ |  |  |
| 成员管理、审计读取 | ✓ |  |  |  |  |

Agent 继承发起人的实时权限，不使用独立的超级权限。高风险 `generate_shot` 创建 PendingAction；非 Owner 不可批准自己的请求，Owner 自批准作为显式 override 写入审计。每次 resume 和工具调用重新查询会话及成员权限。
