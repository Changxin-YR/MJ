# 一键漫剧自动制作方案

状态：已确定，按此方案执行

## 目标

用户在 Director Studio 粘贴一段小说并提交“完整制作”后，系统自动完成故事结构化、角色/剧集/场景/分镜创建，并将首轮图像生成任务排入队列；后续视频、配音、检查和时间线渲染通过可恢复的异步生产运行继续完成。

## 当前范围

第一阶段先交付一个可运行的最短闭环：

1. Director 接收长故事文本和制作选项。
2. 使用 Qwen Plus 输出并校验结构化制作计划。
3. 在当前项目中创建故事、角色、剧集、场景和镜头。
4. 为镜头建立 `STORYBOARD_READY` 状态，并创建图像生成 Job。
5. 返回生产运行 ID、创建记录和任务列表，前端显示进度。
6. 保留预算、Scope、幂等键、审计和暂停/继续边界。

第二阶段接入图像完成后的自动视频/配音链、Inspector 重试、时间线同步与渲染。媒体生成仍由现有 Provider Gateway、Outbox、Celery Worker 和 MinIO 负责。

## 交互模式

- `ANALYZE`：只分析，不创建数据，不产生媒体费用。
- `AUTOPRODUCE`：创建完整制作计划并执行结构化落库；开始前显示计划摘要和预算估算。
- 单镜头 `GENERATE_*`：保留现有人工审批流程。

第一阶段的 `AUTOPRODUCE` 默认采用“结构自动确认、媒体任务可暂停”的模式。用户可以在生产运行面板中查看阶段、创建数量、生成 Job 和错误。

## 结构化计划

计划使用 Pydantic 校验，包含：

- `characters`：姓名、背景、视觉 DNA、声音描述和 Prompt Anchor
- `episodes`：集号、标题、概要
- `scenes`：所属集、场景标题、地点/时间描述
- `shots`：所属场景、描述、动作、对白、情绪、镜头参数、时长、提示词、角色引用
- `options`：画风、默认时长、是否自动生成图像

模型输出不得直接执行 SQL；只有通过 Schema、项目 Scope、角色引用和数量/时长预算校验后，才进入写入事务。

## 约束

- 角色、集、场景和镜头创建必须绑定当前 workspace/project。
- 生产运行和生成任务使用幂等键，重复提交不重复创建。
- 单次自动制作必须有镜头数、时长和预算上限。
- 不自动绕过人工审核；自动创建的结构记录写入审计，媒体审核继续使用现有 Review/Inspector 流程。
- 配音先支持每镜头单一对白音轨；多角色对白需要后续增加 speaker/voice_id/dialogue_segments 数据结构。
- 百炼 Agent App 不作为第一阶段依赖；继续使用当前 FrameForge Director + DashScope 模型。

## 验收标准

1. Director Studio 可粘贴至少一章小说并提交 `AUTOPRODUCE`。
2. 成功创建故事、角色、剧集、场景和不少于一个镜头。
3. 镜头状态可进入 `STORYBOARD_READY`，图像 Job 进入队列。
4. 重复请求不会产生重复结构或重复 Job。
5. 越权项目、无效角色引用、超预算和非法模型输出会被拒绝并记录原因。
6. 原有 `ANALYZE`、单镜头生成、审批和 E2E 流程保持可用。

## 后续阶段

图像完成后，根据生产运行的阶段状态自动排入视频和配音；所有媒体完成并通过检查后创建时间线、同步已审镜头并渲染最终视频。该阶段单独验证远程任务轮询、费用上限、失败重试和人工暂停。
